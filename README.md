# TJ Organization

Private legal file-organization prototype for TJY Law.

## Current Flow

- Prototype login screen
- Home page showing all clients as `Last Name, First Name`
- Client list automatically sorted A-Z by last name
- Add Client form
- Each client starts completely blank
- Custom folder titles per client
- Sticky-note style notes per client
- Data saves in browser localStorage while testing

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL Vite gives you, usually:

```text
http://localhost:5173/
```

## Build

```bash
npm run build
```

## Important

This is still a frontend prototype. Do not upload real client/legal files until real authentication, private database access, and secure file storage are connected.
